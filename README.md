# 🚢 Titanic Data Analysis using Python

This project explores the **Titanic dataset** to uncover patterns that influenced passenger survival.  
It demonstrates data analysis, visualization, and feature exploration using Python libraries such as **NumPy, Pandas, Matplotlib, and Seaborn**.

---

## 📊 Features of the Project

- Data cleaning and preprocessing  
- Handling missing values and data types  
- Exploratory Data Analysis (EDA)  
- Correlation heatmap and statistical insights  
- Visualizations for age, gender, class, and survival rate  
- Feature relationships and survival probability patterns  
- Insights for building predictive models (Machine Learning ready)
